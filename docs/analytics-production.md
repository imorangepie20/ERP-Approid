# Spring 생산 진척 분석 계약

ANL-03의 생산 진척/지연만 다룬다. 영업·재고 분석, 사업장 분리와 재고회전율은 후속 범위이며
현재 단일 공장 스키마에 없는 사업장 필터나 설비 가동률을 추정하지 않는다.

## 조회와 권한

`GET /api/core/analytics/production/progress`는 모든 인증 사용자에게 허용한다. 쓰기 endpoint는 없고
DB 읽기는 read-only/repeatable-read 트랜잭션으로 요약과 행을 같은 스냅샷에서 계산한다.
기존 JWT/Core 클라이언트를 재사용하며 분석 조회는 오더 상태·현재고·감사를 변경하지 않는다.

| 매개변수 | 기본값·규칙 |
| --- | --- |
| from, to | 완료예정일 포함 범위, 서울 오늘−30일~오늘+30일, 최대366일 |
| itemId | 생략 시 전체, 양수 PK; 존재하지 않는 품목404 |
| status | active(지시/진행중), all 또는 지시/진행중/완료/마감/취소 |
| keyword | 최대128자, 오더번호·품번·품명·담당의 대소문자 무시 부분 검색; `%`, `_`, `!`는 문자 그대로 |
| sort | dueDate,asc; dueDate/workOrderNo/progressPercent/priority/itemNo + asc/desc만 허용 |
| page, size | 0-based page0~10000, size1~100, 기본20; 범위 밖 페이지는 빈 행 |

잘못된 날짜·기간·필터·정렬·페이지는 trace ID를 포함한 공통 `INVALID_INPUT` 400이다.
비로그인401, 지원하지 않는 쓰기 메서드405다. 정렬의 비율 null은 마지막이며 동률은 오더번호/ID로 안정화한다.

## 계산과 이력 경계

기간은 **오더의 완료예정일로 대상을 선택**한다. 반환 `asOf`는 조회 시각(UTC), `timeZone`은 Asia/Seoul이다.
기간 종료일 당시 상태/수량을 복원하는 과거 분석이 아니다. 현재 DB 스냅샷의 누적 양품·불량을 사용하고
예전 저장 `progress` 값을 그대로 신뢰하지 않는다.

- 진척률 = (누적 양품+불량)/지시수량×100.
- 남은 지시량 = max(지시수량−양품−불량,0).
- 입력 실적 수율 = 양품/(양품+불량)×100. 실적0이면 null이며 완제품 검사 수율이 아니다.
- 지연 = 현재 지시/진행중이고 완료예정일이 서울 오늘 이전. 오늘 납기·완료·마감·취소는 제외한다.
- 활성 오더 진척 평균과 취소를 제외한 실적 오더 수율 평균은 **오더별 단순 평균**이다.
  오더별 비율을 소수2자리로 반올림한 뒤 평균도 소수2자리로 반올림한다.
- 요약은 모든 필터 결과를 대상으로 하며 페이지와 무관하다. 대상 오더 수를 함께 반환하고 대상0이면 평균null이다.
- 과거 V13 이전 초과 실적은 원 수량을 보존한다. `overActual=true`, 두 비율null, 평균 대상에서 제외하고
  화면에서 확인 경고를 표시한다. 기존 이력을 수정하거나 정상 수량으로 보정하지 않는다.
- 행의 qty/goodQty/defectQty/remainingQty는 품목 기본단위로 표시한다. kg·EA 등 다른 단위 수량을 합산하지 않는다.

## 화면과 검증

`/analytics`는 실제 API 기반 생산 분석이다. 공통 달력, 품목/상태/검색 적용, 정렬·페이지,
실적 새로고침, 로딩·빈 상태·trace 오류/재시도와 오더별 drill-down을 제공한다.
오더 링크는 `/production/orders?keyword=...`이며 실제 작업오더 조회로 연결된다.
운영 대시보드와 MRP 링크도 제공한다. 샘플 수치나 DataContext fallback은 없다.
대시보드의 생산 분석 링크는 적용된 품목 ID를 전달한다. 과거 집계 기간을 현재 진척 기간으로
오해하지 않도록 기간은 전달하지 않고 생산 분석의 서울 오늘±30일 기본값을 사용한다.

관련 검증:

- Spring `ProductionProgressIntegrationTest`: 수량/진척/수율/오늘·과거 납기/요약과 페이지/현재고·감사 불변,
  특수문자 필터, 과거 초과 실적, 인증·입력·404/405·OpenAPI.
- `productionAnalysis.test.ts`, `Analytics.test.tsx`: 인증 GET/검색 인코딩/응답 검증, 실제 단위·비율·null,
  필터/페이지/정렬·오더 링크, 오류/재시도·초과 경고와 axe(색상 대비·랜드마크 제외).
- 격리 Chromium: 실제 누적 실적50%/80% → 변경 후80%/75%, 지연·잔량·현재고 불변과 읽기 역할 drill-down.

설비/공정 실제시간·불량 원인·원가 차이는 원천 이력이 없어 제공하지 않는다.
새 변경의 원격 CI는 커밋/푸시 전에는 검증된 것으로 표시하지 않는다.
