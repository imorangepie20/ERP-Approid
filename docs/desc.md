## 1. 문서 개요

### 1.1 목적
본 문서는 **중소 제조기업(종업원 300인 이하)**을 위한 ERP의 기능 범위를
정의하고, 각 모듈이 제공해야 할 화면·기능·데이터를 명시한다.

### 1.2 대상 기업 유형
| 유형 | 특성 | 주요 반영 기능 |
| --- | --- | --- |
| 다품종 소량생산 (금형/기계부품) | 작업오더 위주, 공정별 실적, 외주 활용 | 작업오더, 공정별 수율, 외주관리, 원가 |
| 다품종 대량생산 (조립/전자) | 라인 생산, 계획 생산, Lot 추적 | 생산계획, 라인별 가동률, Lot/불량 추적 |
| 소분업 (식품/화장품/소재) | 레시피(BOM) 운전, 유통기한, Lot 단위 관리 | 레시피 관리, Lot 추적, 선입선출, 품질검사 |

> 공통 운영 모델: 견적/수주 → 생산계획 → 작업오더 → 자재 출고 →
> 생산(공정/외주) → 검사 → 입고(재고) → 출하/매출 → 원가·결산.

#### 1.2.1 중소기업 적용 시나리오 (2026 시즌)
중소기업중앙회·중소기업연구원 발표 기준 중소 제조기업의 디지털 전환은
수요 대비 공급망 가시성 확보와 원가 역산이 핵심 과제이며, 본 ERP는
다음 운영 제약을 추가로 요구한다.

| 구분 | 주요 대상 | ERP 반영 포인트 |
| --- | --- | --- |
| 1차 금속/기계 부품 | 금형, 사출, 절삭/연마 가공 | 공정별 표준시간 관리, 설비 가동률, 외주 단가 관리 |
| 전기·전자 조립 | PCBA, 기구 조립, 완품 조립 | BOM 다단계 전개, 대체/대기 자재, Lot 단위 불량 추적 |
| 식품/소재 소분 | 배합, 충진, 포장, 보관 | 레시피 BOM, 유통기한/선입선출, 위해요소 관리(HACCP) |

사업 조건: **원가 구조 역산**(재료비+노무비+경비+외주비), 수납기일 및
보관료 관리, **조달 리드타임** 기반 자재 발주 시점 산출, 다품종
제품의 **수주 생산**과 **계획 생산** 혼재 대응.

### 1.3 적용 범위
- 업무 도메인: 수주/영업, 생산계획, 작업오더, 공정/설비, 자재/구매,
  품질, 재고, 출하, 원가, 회계, 인사
- 적용 채널: 관리자 웹 (본 문서 대상). 현장/작업자 포털, 거래처 포털,
  외부 시스템(세무·은행) 연동은 Phase 4
- 우선순위: Phase 1은 1개 공장(사업장) 운영에 필요한 최소 기능(MVP)

### 1.4 대상 사용자
| 역할 | 권한 요약 |
| --- | --- |
| 대표이사(공장장) | 전 모듈 조회, 승인(원가/결산/할인) |
| 영업 담당자 | 견적/수주, 단가, 출하, 미수 관리 |
| 생산관리자 | 생산계획, 작업오더, 공정 진척, 외주 발주 |
| 작업자(팀장) | 본인 공정 실적 입력, 불량/이상 보고 |
| 자재/구매 담당자 | 발주, 입고, 재고, 안전재고 |
| 품질 담당자 | 검사 기준, 검사 실적, 부적합 처리 |
| 회계 담당자 | 매입/매출, 원가 집계, 세금계산서, 결산 |
| 시스템 관리자 | 사용자/권한, 공통코드, 환경설정, 로그 |

## 2. 도메인 용어 정의
| 용어 | 정의 |
| --- | --- |
| 품목 (Item) | 제품·반제품·자재의 마스터. 품번, 품명, 규격, 단위, 단가 |
| BOM | 제품 구성표. 모품목-자품목, 수량(소요량), 손실율, 대체자재 |
| 공정 (Routing) | 제품의 제조 순서. 공정순서, 표준시간, 작업장(설비) |
| 작업오더 (Work Order) | 생산 지시서. 제품, 수량, 착수/예정일, 우선순위, 상태 |
| 생산계획 | 월/주 단위 생산 수량 계획. 수주/재고 기반 MPS |
| 자재소요 (MRP) | BOM 전개에 의한 자재 필요량 및 발주 시점 산출 |
| Lot | 생산/입고 추적 단위. 제조번호, 생산일, 유통기한, 불량 추적 |
| 불량 (Defect) | 검사 기준 미충족. 불량코드, 원인, 처리(재작업/폐기) |
| 수율 (Yield) | 양품 수량 / 투입 수량. 공정별 품질 지표 |
| 외주 (Subcontract) | 외부 협력사에 위탁한 공정. 외주단가, 납기, 외주재고 |
| 설비 (Equipment) | 작업장의 기계/라인. 가동률, 점검, 고장 이력 |
| 원가 (Cost) | 재료비+노무비+경비+외주비. 표준원가/실제원가 차이 |
| 수납기일 | 고객사별 대금 결제 기한. 미수금 관리 기준 |
| 리드타임 (Lead Time) | 발주~입고까지의 소요일. 안전재고/발주점 산출 근거 |
| 안전재고 | 품절 방지용 최소 보유 수량. 발주점 = 안전재고 + 소비×리드타임 |

## 3. 모듈별 기능 정의

### 3.1 대시보드
- KPI 카드: 당월 매출, 당월 생산액, 수주 잔량, 납기 준수율, 불량률,
  재고 회전율
- 생산 추이 (월/주 단위, Chart.js): 계획 vs 실적 비교
- 공정별 가동률 및 작업오더 진행 현황
- 출하/매입/불량 트렌드
- 사업장(공장)별 지표
- 알림: 미납(연체) 수주, 납기 지연 위험 오더, 안전재고 미달 자재,
  설비 점검 예정, 불량률 급증 공정

### 3.2 영업·수주
- 견적 관리: 견적번호, 고객, 품목, 수량, 단가, 납기, 유효기간
- 수주 등록: 견적/신규 → 고객 선택 → 품목/수량 → 단가/납기 → 확정
- 수주 현황 (대기/확정/생산중/출하완료/취소)
- 단가 관리: 고객별 단가표, 거래처별 수납기일
- 미납(연체) 관리: 미수금 목록, 독촉 이력
- 출하 관리: 출하 지시, 송장, 배차, 출하 확정 → 매출

### 3.3 생산계획·작업오더
- 생산계획: 월/주 단위 품목별 계획 수량 (MPS), 수주/예측 기반
- **작업오더**: 제품, 수량, 착수/완료 예정일, 우선순위, 담당자,
  공정(Routing) 자동 전개
- 공정별 진척: 공정 완료 수량, 진행률, 지연 여부
- 작업오더 상태: 지시/진행중/완료/마감/취소
- **수율 관리**: 양품/불량 수량 입력, 공정별 수율 산출
- 보강/재작업 처리, 작업오더 변경 이력
- 우선순위 기반 작업장(설비) 일정 배정

### 3.4 자재·구매
- 자재 마스터: 품번, 규격, 단위, 단가, 리드타임, 안전재고
- **MRP**: BOM 전개 → 필요량 산출 → 발주 시점/수량 제안
- 발주(구매): 거래처, 단가, 납기, 입고 예정일
- 입고: 발주 대비 입고 수량, 검수(불량 반품), 단가 차이
- 거래처 마스터: 연락처, 수납기일, 거래 단가표
- 안전재고 미달 알림, 발주 제안 목록

### 3.5 재고
- 창고/위치 관리 (자재창고, 반제품, 완제품)
- 입/출고 이력: 입고, 출고(생산용), 출하, 이동, 재고실사
- **Lot 관리**: 제조번호별 입고/출고, 유통기한, 선입선출(FIFO)
- 재고 현황: 품목별 가용/불량/이동중 재고
- 재고실사 및 차이 처리, 회계 연동
- 안전재고 대비 현재고 시각화

### 3.6 품질
- 검사 기준: 품목/공정별 검사 항목, 기준값, 검사 방법
- **검사 실적**: 자재 입고검사, 공정 검사, 완제품 검사
- 부적합 처리: 불량코드, 원인, 처리(재작업/폐기/특채), 재검사
- **불량 추적**: Lot별 불량 내역, 원인별 집계, 파레토
- 수율 통계: 공정별/품목별 수율, 불량률 트렌드
- 고객 불만(클레임) 접수 및 조치 이력

### 3.7 공정·설비
- 공정(Routing) 마스터: 공정순서, 작업장, 표준시간, 외주 여부
- 작업장/설비 관리: 설비명, 능력(능력/일), 가동 시간
- **가동률**: 설비별 가동/유휴/고장 시간, OEE 산출
- 설비 점검: 점검 주기, 점검일, 결과 이력
- 고장/수리 이력, 예방보전 일정
- 표준시간 관리: 공정별 표준시간, 실적시간 비교

### 3.8 외주
- 외주처 마스터: 협력사, 공정, 단가, 납기
- 외주 발주: 외주 공정 지시, 자재 반출/반입
- 외주 실적: 완성 수량, 불량, 납기 준수
- 외주 재고: 협력사에 반출된 자재 관리
- 외주비 정산: 단가 × 수량 → 매입(회계 연동)

### 3.9 원가·회계
- **표준원가**: 재료비(BOM×단가)+노무비(표준시간×임율)+경비+외주비
- **실제원가**: 작업오더별 집계 (재료/노무/경비/외주 실적)
- 원가 차이: 표준 vs 실제, 차이 분석
- 전표 관리 (입금/출금/대체)
- 계정과목 마스터 (매출액, 매입원가, 재고자산, 노무비, 외주비, 운영비)
- 채권/채무: 미수금(미납 수주), 미지급금(외주/매입)
- 세금계산서 발행/조회 (고객, 거래처)
- 결산: 월/분기/연 결산 보고서 (손익 요약)

### 3.10 인사·조직
- 조직도: 본부-공장-부서-직위
- 직원 마스터: 인적사항, 입사/퇴사, 소속 공정/작업장
- 근태: 출근/퇴근, 휴가, 작업 오더별 작업 시간
- 권한 관리: 역할(Role)별 메뉴 권한, 공장별 데이터 권한
- 급여/상여 (기본 항목 관리, 상세 정산은 Phase 3)

### 3.11 게시판·알림
- 공지사항 (전체/공장/대상별)
- 현장 알림: 납기 지연 위험, 자재 부족, 설비 고장, 불량 발생
- 관리자 알림: 원가 차이 임계 초과, 재고 부족, 결산 대기
- 문자/LMS/이메일 발송 및 결과 이력, 템플릿 관리
- 파일 첨부/다운로드

### 3.12 시스템 관리
- 사용자 관리: 계정 생성, 역할 할당, 비밀번호 정책
- 메뉴/권한 관리 (화면 단위), 공통 코드 관리 (불량코드, 단위, 창고,
  검사방법, 작업오더 상태)
- 환경 설정: 공장/작업장, 휴일, **원가 기본값(임율, 경비율)**,
  안전재고 정책, 수납기일 기본값
- 로그 관리 (접속 로그, 민감 변경 이력: 원가/단가/결산)
- 백업/복구, 데이터 내보내기

## 4. 주요 업무 흐름
1. **수주 → 생산**: 견적 → 수주 확정 → 생산계획 → 작업오더 → 공정 진행 → 완료
2. **자재**: MRP 필요량 → 발주 → 입고/검수 → 재고 → 생산 출고
3. **생산**: 작업오더 지시 → 자재 출고 → 공정별 실적 → 검사 → 입고(완제품)
4. **출하·매출**: 출하 지시 → 송장 → 출하 확정 → 매출 → 수납기일 관리
5. **원가·결산**: 작업오더별 원가 집계 → 표준/실제 차이 → 결산

| 품목/BOM | `pages/Products` + `forms/*` | 품목 마스터/BOM |
| 작업오더 | `pages/pos/customer-order` | 수주→지시 플로우 재사용 검토 |
| 생산 일정 | `pages/Calendar` + `tables/*` | 작업오더 캘린더/진척 |
| 외주 정산 | `pages/tables/TablePlugins` | 정산 확정 그리드 |
| 게시판/알림 | `pages/email/*` + `ScrumBoard` | 목록/상세, 결재 워크플로 |
| 시스템 관리 | `pages/Settings` | 권한/코드/원가 설정 |
| UI/Forms/Charts | 템플릿 내 참조용 | 개발용 컴포넌트 자산 |

> 템플릿의 식당 POS(주방/테이블/메뉴), AI Studio, Gallery, Pricing, ScrumBoard 등은
> 제조 ERP 1차 범위에서 비활성화하거나 용도를 변경한다.

## 7. 개발 우선순위 (제안)
| Phase | 모듈 | 목표 |
| --- | --- | --- |
| Phase 1 (MVP) | 대시보드, 수주, 품목/BOM, 생산계획/작업오더, 자재/재고, 출하 | 1공장 수주생산 운영 |
| Phase 2 | 품질, 공정/설비, 외주, 게시판/알림 | 운영 자동화 |
| Phase 3 | 원가 정산 고도화, 회계·재무, 인사 | 전사 ERP + 원가 관리 |
| Phase 4 | 현장/거래처 포털, 세무·은행 연동, 다공장, SMS/LMS | 외부 연동 및 확장 |

> 원가(표준/실제) 기능은 Phase 3 원가 정산 고도화와 묶어 구현한다. 단,
> 작업오더별 재료비/노무비 실적은 Phase 1 작업오더에서 확보한다.
